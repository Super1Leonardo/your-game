# Твоя Игра (SvelteKit Edition)

Браузерная версия интеллектуальной викторины для компании друзей за одним устройством. Проект реализован на **Svelte 5** с использованием **Runes**.

## 🛠 Технологический стек

- **Фреймворк:** SvelteKit (Static Adapter)
- **Core:** Svelte 5 (Runes: `$state`, `$derived`, `$effect`)
- **Стилизация:** Tailwind CSS 4 + DaisyUI
- **UI Компоненты:** Melt UI (Headless accessibility)
- **Тестирование:** Playwright
- **Язык:** TypeScript

## 🚀 Запуск проекта

Для запуска локально (требуется Node.js LTS):

```bash
# Установка зависимостей
npm ci

# Запуск в режиме разработки
npm run dev

# Сборка проекта (в папку public)
npm run build

# Предпросмотр сборки
npm run preview
🏗 Архитектура приложения
Проект построен по принципу модульного монолита с четким разделением ответственности.

Управление состоянием (State Management)
Логика игры полностью отделена от UI и находится в src/lib/state. Используется реактивность Svelte 5 Runes.

gameStore.svelte.ts — Глобальный синглтон, хранящий состояние игры (игроки, вопросы, таймеры, текущий раунд). Состояние автоматически синхронизируется с localStorage через $effect, что позволяет переживать перезагрузку страницы (F5).

devStore.svelte.ts — Состояние режима разработчика.

Структура проекта
src/routes/ — Страницы приложения (File-based routing).

/setup — Настройка сессии (игроки, паки).

/editor — Редактор вопросов.

/game — Основное игровое поле.

/final — Логика финального раунда.

src/lib/components/ — UI компоненты, разбитые по доменам (game, editor, setup, ui). Все компоненты используют семантическую верстку.

src/lib/utils/ — Чистые функции бизнес-логики (answerChecker, timer, keyboardManager).

✨ Реализованные фичи
Основной функционал
Полный цикл игры: Настройка -> Раунды 1/2 -> Финал -> Результаты.

Механики: "Кот в мешке", "Аукцион", таймеры, подсчет очков.

Управление клавиатурой (блокировка права ответа первым нажавшим).

Экстрафичи (Extra Features)
В проекте реализованы следующие дополнительные возможности:

Редактор тем и вопросов 📝

Встроенный визуальный редактор (/editor), позволяющий создавать свои пакеты вопросов.

Валидация пустых полей.

Импорт и экспорт пакетов 💾

Возможность сохранить созданный пак в JSON файл.

Загрузка сторонних паков через Drag & Drop.

Персонажи игроков 🖼️

Возможность загрузки пользовательских аватаров для каждого игрока.

Аватары отображаются в игре и на экране результатов.

Умная проверка ответов 🧠

Система "Fuzzy matching" (расстояние Левенштейна).

Прощает опечатки (1 ошибка для коротких слов, 2 для длинных).

Игнорирует регистр и букву "ё".

Настройка количества игроков 👥

Поддержка от 2 до 6 игроков (динамическое изменение интерфейса).

Темы оформления 🎨

Переключение светлой/темной темы (DaisyUI themes).

Сохранение выбора в браузере.

Анимации интерфейса ✨

Плавные переходы между экранами.

Анимации появления вопросов и результатов финала.

🛠 Dev-mode (Режим разработчика)
Для удобства проверки реализован Dev-mode (переключатель в футере сайта).
Возможности:

Просмотр правильных ответов прямо в карточке вопроса.

Подсветка скрытых типов вопросов ("Кот в мешке", "Аукцион") на табло.

Кнопки для быстрого управления счетом игроков (+/-).

Принудительное завершение таймера.
```
